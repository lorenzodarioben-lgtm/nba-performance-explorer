# API catalog — final Shot 1 closeout

All paths below are same-origin public application APIs. Methods are GET unless stated; supported route families return405for unsupported methods. Shared schemas under `packages/contracts/src` are the exact parameter/response authority. No arbitrary upstream-URL proxy, account/bookmark API, live scoreboard/PBP API or paid source is implemented. Source/cache configuration is not a connectivity probe. `CLOSEOUT_ACCEPTANCE.json` records46successful contract checks and5error/method checks against a local production-mode genuine-provider server.

## Identity, scope and errors

NBA players use decimal strings. Teams use `nba:161061…`; recorded2023-24regular games `nba:00223…`,2024playoff games `nba:00423…`,2018shot games `nba:00417…`; research people `br:…`,groups `study:…`; Wikidata entities `wd:Q…`. Identifiers cannot be cast across namespaces. Seasons useYYYY-YY, calendar datesYYYY-MM-DD; month/day lookupsMM-DD. Regular/playoffs stay separate. Source calendar dates and unknown tipoff timezone do not establish UTC/local tipoffs.

Input errors return400; valid absent identities/games generally404; invalid source payloads502; disabled/unavailable/busy sources503; timeouts504. Responses use sanitized `ApiErrorResponseSchema` code/message. Domain-specific unsupported/missing-season states may instead return200with null/explicit status; an empty valid filtered cohort is not a failure. No failed genuine provider substitutes fixtures. Repeated query parameters, unknown fields, duplicate IDs, invalid dates/cardinality and reversed ranges are rejected where strict research contracts apply.
